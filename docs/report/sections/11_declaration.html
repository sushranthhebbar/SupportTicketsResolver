Declaration of AI tool use

I used Claude Code, Anthropic's command-line coding assistant running Claude models, throughout this project, and the use was substantial. The assistant did the following under my direction: it wrote and edited code in the repository, including the pipeline, guardrails, evaluation harness, review application and tests; wrote the analysis scripts for calibration, error analysis, confidence intervals and the fairness audit; ran experiments and the evaluation runs; read the 50 validation drafts against the cited articles; drafted the analysis documents in the repository (the development error analysis, the governance documents, the credential scan and this report); and drafted text in the stage workbooks and the effort log, including the estimated hours. Beyond the assistant, I relied on the supplied course pack (the transcripts, data sets, specifications and templates), on open-source libraries (Chroma, a LangChain text splitter, the MiniLM sentence embedding model, FastAPI, requests, python-dotenv and python-docx), and on the Qwen 3.8 27-billion-parameter model served by Groq as the language model inside the system. The prompts that run in the system were drafted with the assistant and are listed in Appendix A.

The course asks that the problem statement, the evaluation interpretation and the reflection come from my own judgement. The problem statement in Section 3.7 is the text from my discovery workbook. The interpretation and reflection in Sections 7, 9 and 10 were drafted by the assistant from the workbooks and the result files in the repository. Every number in this report comes from a file in the repository, and each is stated with the data it was measured on.

Examples where I overrode or corrected the assistant, or where its output needed correcting, are these. When it told me that a validation run did not exist, I had in fact started it, and I corrected the record. When the course documents gave the wrong deadline, I corrected it to 22 November. I decided not to carry out the two-assessor review of the drafts for lack of time, even though the assistant had built the review packet, so the hallucination rate and citation accuracy are reported as not measured and the assistant's own informal read is labelled as such. I chose which of its suggested guardrail changes to build (the input check and the logging of classifier failures) and which to leave as known gaps. The assistant's first guardrail demonstration used an invented key that resembled a real one and was rejected by the repository host's secret scanner, so I approved rewriting my unpushed commits to remove it; a scan of the whole history found no real credential. The hours in the effort log are estimates that the assistant produced from the commit history and the plan, and are not a timesheet.
